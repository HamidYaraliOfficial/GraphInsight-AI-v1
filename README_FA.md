## ۱. GraphInsight AI چیست؟

GraphInsight AI یک نرم‌افزار **محلی و آفلاین** (پایتون + Streamlit) است که *تصویر یک نمودار* — شکل اسکن‌شده، اسکرین‌شات یا شکل داخل PDF — را دوباره به **داده‌های عددی** قابل‌استفاده در پژوهش تبدیل می‌کند:

* جدول نقاط X / Y برای هر منحنی، همراه با مختصات پیکسلی، **میزان اطمینان** و **منشأ (Provenance)** هر نقطه،
* **مدل‌های ریاضی تقریبی** (معادله به‌صورت متن، LaTeX، پایتون و اکسل) با R²، RMSE، MAE، AIC، BIC، اعتبارسنجی متقاطع و عدم‌قطعیت پارامترها،
* **مشتق، انتگرال، مساحت بین منحنی‌ها، بیشینه/کمینه، نقاط عطف و تقاطع‌ها**،
* **آمار** و مقایسه بین منحنی‌ها،
* **گزارش علمی** Word / PDF (فارسی *یا* انگلیسی با پشتیبانی راست‌به‌چپ)، فایل **Excel** چندبرگه با جدول‌های واقعی، فرمول و نمودار، و همچنین CSV، JSON، PNG/SVG و بستهٔ ZIP.

اصول طراحی (طبق شرح پروژه):

* **اولویت با دقت و اعتبار علمی است.** هر چیزی که قابل بازیابی نباشد «نامشخص» گزارش می‌شود؛ هیچ عنوان محور، واحد، نوع خطا یا معادله‌ای حدس زده نمی‌شود.
* **منشأ هر نقطه صریح است.** هر نقطه یکی از برچسب‌های `marker` (Marker واقعی تصویر)، `reconstructed` (بازسازی از مسیر مرکزی خط)، `interpolated` (پر کردن شکاف)، `vector_vertex` (رأس دقیق مسیر برداری PDF) یا `manual` (ورود دستی) را دارد. نقاط بازسازی‌شده هرگز به‌عنوان اندازه‌گیری اصلی معرفی نمی‌شوند.
* **همه‌چیز محلی است.** بدون سرویس ابری، بدون کلید API، بدون ارسال داده.
* **انسان در حلقه می‌ماند.** هر مرحلهٔ خودکار (ناحیهٔ نمودار، کالیبراسیون، رنگ‌ها، نقاط) با Undo / Redo قابل اصلاح دستی است.

## ۲. تور تصویری (خروجی واقعی موتور)

> همهٔ تصاویر این README با موتور واقعی و از نمودارهای مصنوعی پوشهٔ `sample_charts/` (با برچسب **Sample Data**) ساخته شده‌اند؛ ماکت نیستند. اسکریپت‌های ساخت: `scripts/make_readme_assets.py` و `scripts/make_sample_outputs.py`.

### ۲.۱ از تصویر تا داده — مراحل پردازش

نمونهٔ *Force (N)* با چهار منحنی (`PAM`، `PAMCZ3%`، `PAMCZ1%`، `PA`): تصویر اصلی ← ناحیه نمودار و تیک‌های شناسایی‌شده ← خوشه‌های رنگی ← مسیر مرکزی با دقت زیرپیکسل ← بازسازی ← نتایج تحلیل. در این نمونه محور افقی **عنوان ندارد**؛ نرم‌افزار آن را «نامشخص» ثبت می‌کند و چیزی نمی‌سازد.

## ۴. شروع سریع (نصب و اجرا)

### ۴.۱ پیش‌نیازها

* **پایتون ۳.۸ یا جدیدتر** (نسخه‌های ۳.۱۰ تا ۳.۱۲ توصیه می‌شوند). `pip` به‌طور خودکار جدیدترین نسخهٔ بسته‌هایی را نصب می‌کند که با *پایتون شما* سازگارند — روی پایتون ۳.۸ و ۳.۹ نسخه‌های قدیمی‌تر NumPy 1.x / SciPy / pandas 2.0؛ کد برای هر دو نسل توابع سازگارکننده دارد (در بخش ۱۴ آمده چه چیزی روی نسخه‌های قدیمی راستی‌آزمایی شده و چه چیزی نه).
* **Tesseract OCR** (توصیه‌شده — اعداد محورها را خودکار می‌خواند؛ بدون آن باید مقادیر محور را دستی وارد کنید).
  * ویندوز: <https://github.com/UB-Mannheim/tesseract/wiki> (مسیر پیش‌فرض نصب خودکار شناسایی می‌شود؛ در غیر این صورت `TESSERACT_CMD` را در `.env` تنظیم کنید).
  * اوبونتو / دبیان: `sudo apt install tesseract-ocr`   ·   مک: `brew install tesseract`
  * بستهٔ اختیاری OCR فارسی: `tesseract-ocr-fas` و سپس «زبان OCR» را در تنظیمات روی `eng+fas` بگذارید.
* اینترنت **فقط برای نصب اولیهٔ بسته‌های پایتون** لازم است؛ پس از آن برنامه کاملاً آفلاین کار می‌کند.
* اختیاری: **LibreOffice** (فقط برای ساخت PDF فارسی وقتی `arabic-reshaper` / `python-bidi` در دسترس نباشند) و فونت **Vazirmatn** در `assets/fonts/`.

### ۴.۲ ویندوز

```text
۱. GraphInsight-AI.zip را از حالت فشرده خارج کنید
۲. (اختیاری) روی install.bat دوبار کلیک کنید  – محیط .venv را می‌سازد و بسته‌ها را نصب می‌کند
۳. روی run.bat دوبار کلیک کنید
۴. مرورگر روی http://127.0.0.1:8501 باز می‌شود
```

`run.bat` نسخهٔ پایتون (≥ ۳.۸) را بررسی می‌کند، در صورت نیاز `.venv` می‌سازد، بسته‌ها را **فقط وقتی `requirements.txt` تغییر کرده** نصب می‌کند (هش SHA-256 فایل در `.venv` ذخیره می‌شود)، نبودن Tesseract را هشدار می‌دهد، نشانی محلی را چاپ می‌کند و **در صورت خطا پنجره را باز نگه می‌دارد** تا پیام را بخوانید. اسکریپت‌ها از هر مسیری کار می‌کنند (مسیرها از محل خود فایل گرفته می‌شود).

### ۴.۳ لینوکس و macOS

```bash
unzip GraphInsight-AI.zip && cd GraphInsight-AI
chmod +x run.sh install.sh      # فقط اگر مجوز اجرا از بین رفته بود
./install.sh                    # اختیاری: ساخت .venv و نصب بسته‌ها  (--force نصب مجدد، --check فقط بررسی)
./run.sh                        # اجرای داشبورد -> http://127.0.0.1:8501
```

### ۴.۴ نصب دستی (هر سیستم‌عامل)

```bash
python -m venv .venv
source .venv/bin/activate            # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

`requirements.txt` بازه‌های سازگار نسخه‌ها را دارد؛ `requirements-lock.txt` نسخه‌های دقیقی را نشان می‌دهد که موتور و ۷۰ تست خودکار با آن‌ها اجرا شده‌اند.

## ۵. راهنمای استفاده

### ۵.۱ بارگذاری تصویر — صفحهٔ «تحلیل جدید»

1. صفحهٔ **تحلیل جدید** را باز کنید و یک یا چند فایل (PNG، JPG/JPEG، TIFF، BMP، WEBP، SVG، PDF) را بکشید و رها کنید. فایل‌ها از نظر پسوند، امضای فایل (magic bytes) و حجم (≤ ۶۰ مگابایت) اعتبارسنجی می‌شوند و **هرگز اجرا نمی‌شوند**.
2. برای **PDF** صفحه را انتخاب کنید؛ PDF برداری داده را دقیق می‌دهد (`vector_vertex`) و PDF اسکن‌شده مثل تصویر تحلیل می‌شود.
3. در صورت نیاز **تنظیمات استخراج** را باز کنید (زبان OCR، حذف نویز، اصلاح کجی، تلورانس رنگ، تعداد نقاط، روش نمونه‌برداری، حالت منحنی، اجبار نوع نمودار، مقیاس محورها).
4. **شروع تحلیل خودکار** را بزنید. نوار پیشرفت مرحله را نشان می‌دهد؛ برای لغو روی هر دکمهٔ دیگر کلیک کنید. نتیجه شامل هشدارهاست (وضوح پایین، نبود OCR، تیک‌های ناخوانا و …).
5. زبانهٔ **امتحان با نمونه** نمودارهای مصنوعی را اجرا می‌کند (همیشه با برچسب *Sample Data*).

### ۵.۲ کالیبراسیون — صفحهٔ «پردازش تصویر»

این صفحه تصویر اصلی و پردازش‌شده، **ناحیهٔ نمودار** (سبز) و **تیک‌ها** (صورتی) را روی نمودار قابل زوم و جابه‌جایی نشان می‌دهد.

* **ناحیه نمودار** – اگر کادر اشتباه است، گوشه‌های آن (و در صورت نیاز چرخش) را وارد کنید و «اعمال و استخراج دوباره» را بزنید.
* **کالیبراسیون** – جدول همهٔ تیک‌های شناسایی‌شده (موقعیت پیکسلی و مقدار OCR) را نشان می‌دهد. ردیف‌ها را ویرایش/اضافه کنید (حداقل ۲، **ترجیحاً ≥ ۳** تا برازش قابل بررسی باشد)، **نوع مقیاس** را انتخاب کنید (`auto`، `linear`، `log10`، `log2`، `ln`، `piecewise` برای محور غیریکنواخت، `categorical`، `datetime`) و دوباره استخراج کنید. یا مقدار محور را در لبه‌های ناحیهٔ نمودار وارد کنید. *اطمینان کالیبراسیون* و خطای برازش (پیکسل) نمایش داده می‌شود.
* **عنوان و واحد محورها** – اگر OCR نتوانست بخواند، خودتان وارد کنید؛ وگرنه در همهٔ گزارش‌ها **نامشخص** می‌ماند.

### ۵.۳ استخراج و اصلاح نقاط — صفحهٔ «دیجیتالی‌سازی»

* یک سری را انتخاب کنید؛ نقاطش روی تصویر رسم می‌شود. می‌توانید نام و رنگ آن را عوض کنید یا سری را **از روی یک رنگ دلخواه دوباره استخراج** کنید (برای منحنی‌های هم‌رنگ/مبهم).
* تنظیمات: تعداد نقاط، روش نمونه‌برداری (`adaptive` در بخش‌های پرانحنا نقاط بیشتری می‌گذارد، `uniform_x`، `uniform_arc`)، وزن انحنا، تلورانس رنگ، حالت متراکم. «استخراج دوباره با این تنظیمات» سری‌ها را بازمی‌سازد و کالیبراسیون را حفظ می‌کند.
* **ویرایش جدول**: مقدار X/Y را تغییر دهید، ردیف اضافه یا حذف کنید. نقاط ویرایش‌شده/افزوده وضعیت `manual` و اطمینان ۱٫۰ می‌گیرند و موقعیت پیکسلی از روی کالیبراسیون دوباره محاسبه می‌شود.
* **Undo / Redo** در نوار کناری است؛ هر ویرایش یک نسخهٔ پشتیبان است و در گزارش پروژه ثبت می‌شود.

### ۵.۴ داده‌کاوی (Data Explorer)

جدول تعاملی همهٔ نقاط با جست‌وجو، فیلتر وضعیت/سری، انتخاب ستون، مرتب‌سازی، **کپی** (جداشده با Tab) و دانلود **CSV / Excel**.

### ۵.۵ تحلیل ریاضی

خانواده‌های مدل را انتخاب کنید (یا **مدل دلخواه** بنویسید، مثلاً `a*x**2 + b*sin(c*x)` — با SymPy به‌صورت ایمن تفسیر می‌شود و هیچ کدی اجرا نمی‌شود)، منبع برازش (`markers` / `dense` / `auto`) و روش مشتق را برگزینید و «اجرای تحلیل» را بزنید. برای هر سری: جدول مدل‌ها (R²، R² تعدیل‌شده، RMSE، MAE، AIC، BIC، CV-RMSE)، رویهم‌گذاری مدل‌های انتخابی، **معادله به‌صورت LaTeX / متن / پایتون / اکسل**، پارامترها با خطای استاندارد و بازهٔ اطمینان ۹۵٪، نمودار باقیمانده، منحنی‌های مشتق، انتگرال معین روی بازهٔ دلخواه، نقاط بحرانی، بخش‌های محدب/مقعر و پلاتوها.

> **مهم:** تابع برازش‌شده فقط *توصیف تقریبی* نقاط دیجیتال‌شده است. با تعداد محدود نقطه چند خانوادهٔ مدل می‌توانند به یک اندازه خوب برازش شوند؛ برنامه هرگز ادعا نمی‌کند «قانون واقعی» را یافته است. قاعدهٔ انتخاب: *ساده‌ترین مدلی که RMSE آن در ۱۵٪ (یا ۰٫۲۵٪ دامنهٔ y) بهترین مدل باشد*؛ در تساوی، BIC تعیین می‌کند.

### ۵.۶ تحلیل آماری، مصورسازی، گزارش‌ها، تاریخچه

* **تحلیل آماری** – آمار توصیفی، هیستوگرام، همبستگی (پیرسون / اسپیرمن / کندال)، رگرسیون، مقایسه و رتبه‌بندی سری‌ها، تقاطع‌ها، عدم‌قطعیت و نمودار Quality Assessment. مقدار p برای نقاط متراکم بازسازی‌شده با پرچم **«بی‌معنا»** نمایش داده می‌شود.
* **مصورسازی** – نمودار اصلی را بازسازی یا نمودار جدید بسازید: رنگ، عنوان، محورها، Legend، بازه، مقیاس لگاریتمی؛ دانلود PNG / SVG / PDF.
* **گزارش‌ها** – زبان گزارش (فارسی / انگلیسی) و فرمت‌ها را انتخاب کنید، «تولید خروجی» را بزنید و فایل‌ها را جدا یا یک‌جا (ZIP) دانلود کنید.
* **تاریخچهٔ پروژه** – همهٔ پروژه‌ها در `data/projects/<id>/` ذخیره می‌شوند. باز کردن، کپی، حذف، خروجی ZIP و بازیابی در رایانهٔ دیگر.

### ۵.۷ خروجی Excel (`*_data.xlsx`)

برگه‌ها: `Overview`، `Original_Metadata`، `Axis_Calibration`، `Extracted_Data`، `Series_1 … Series_N` (برای هر منحنی؛ تعداد به‌صورت پویا)، `Curve_Fitting`، `Model_Parameters`، `Statistical_Analysis`، `Derivatives`، `Integrals`، `Intersections`، `Error_Analysis`، `Confidence`، `Processing_Log`.
جدول‌های واقعی اکسل با فیلتر، ردیف عنوان ثابت، نمودارهای بومی اکسل و **فرمول‌های زنده** در برگه‌های سری (شیب با تفاضل محدود، انتگرال تجمعی ذوزنقه‌ای، منحنی برازش‌شده که از سلول‌های پارامتر در `Model_Parameters` محاسبه می‌شود، باقیمانده). فایل نمونه با LibreOffice بازمحاسبه شد: **۰ خطا در ۳٬۲۷۶ فرمول**.

### ۵.۸ خروجی Word (`*_report_fa.docx` / `*_report_en.docx`)

صفحهٔ عنوان، مشخصات تصویر، اطلاعات نمودار (محورها، واحدها، مقیاس‌ها، بازه‌ها، Legend)، تصویر اصلی، پوشش استخراج، نمودار بازسازی‌شده، جدول‌های عددی (جدول کامل نقاط با وضعیت و اطمینان)، معادلات (تصویر رندرشده، LaTeX، پایتون، اکسل)، پارامترها با بازهٔ اطمینان، شاخص‌های برازش، رتبه‌بندی مدل‌ها، نمودارهای باقیمانده/مشتق/مقایسه، انتگرال‌ها، نقاط بحرانی، آمار، تحلیل علمی مبتنی بر داده، Quality Assessment، فهرست منابع داده (استخراج مستقیم از تصویر / محاسبهٔ ریاضی / برازش آماری / درون‌یابی / ورود دستی) و محدودیت‌ها. گزارش فارسی راست‌به‌چپ است.

* زمان: ۲ تا ۴ ثانیه برای هر نمودار روی CPU لپ‌تاپ (بیشتر صرف OCR).

## ۱۳. محدودیت‌های علمی و فنی

* **تصویر رستری وضوح محدود دارد.** عدم‌قطعیت معمول ±۱ تا ۲ پیکسل است که در برگهٔ *Error_Analysis* به واحد داده تبدیل می‌شود. نقاط بازسازی‌شده از خط، اندازه‌گیری‌های اصلی آزمایشگر نیستند؛ نقاط درون‌یابی‌شده حتی کمتر.
* **معادلات برازش‌شده تقریبی‌اند.** از تعداد کمی نقطه نمی‌توان تابع مولد را تعیین کرد؛ برنامه «مدل تقریبی انتخاب‌شده» و گزینه‌های دیگر را گزارش می‌کند.
* **مشتق نویز را تقویت می‌کند**؛ انتگرال تخمین عددی است. روش محاسبه در همهٔ خروجی‌ها نام برده می‌شود.
* **آزمون‌های آماری به مشاهدات مستقل نیاز دارند.** نقاط متراکم روی خط وابسته‌اند: مقدار p نمایش داده می‌شود اما با پرچم بی‌معنا؛ برای استنباط از Markerهای واقعی (`markers`) استفاده کنید.
* **نوار خطا / ناحیه سایه** – نوع آن (SD، SE، CI، دامنه) مگر آنکه خودتان مشخص کنید، **تعیین نمی‌شود**.
* **پوشش خودکار** – راهبردهای ✅ در بخش ۶. پیاده‌سازی نشده: استخراج مقدار از نمودارهای سه‌بعدی / سطحی / کانتور / نقشهٔ حرارتی، آمار Box و Violin، نمودار قطبی، سانکی / تری‌مپ / شبکه، شمعی، سه‌تایی، راداری. نمودارهای نایکوییست / پارامتریک با اسکلت‌یابی (جزئی).
* **محورها** – کالیبراسیون خودکار برای محورهای پایین/چپ با برچسب عددی کار می‌کند. محور تاریخ‌وزمان، دسته‌ای و غیریکنواخت نیاز به انتخاب دستی مقیاس دارند؛ برچسب‌های آفست مانند «×10³»، برچسب‌های مایل، محورهای متقاطع در میانهٔ نمودار و محور شکسته خودکار خوانده نمی‌شوند.
* **منحنی‌ها** – منحنی‌های تک‌مقداری با برنامه‌ریزی پویا دنبال می‌شوند؛ منحنی‌های هم‌رنگ و هم‌پوشان قابل تفکیک نیستند (هشدار داده می‌شود)؛ Markerهای نازک (`x`، `+`) به‌عنوان Marker شناسایی نمی‌شوند؛ جایی که منحنی به محورها می‌چسبد حدود ۱٪ بازهٔ x ممکن است از دست برود.
* **OCR** – روی تصاویر تمیز، اعداد درست خوانده شدند؛ متن محو و بسیار ریز (نمونهٔ `09`) خوانده نشد. عنوان‌ها و Legend به Tesseract وابسته‌اند و ممکن است اشتباه بخوانند (`mg` ← `ma`) — بررسی کنید. متن فارسی نمودار به بستهٔ زبان `fas` نیاز دارد.
* **زبان شکل‌ها** – شکل‌های matplotlib در گزارش‌ها برچسب انگلیسی دارند (متن گزارش فارسی است).
* پروژهٔ فعال در نشست مرورگر نگه‌داری می‌شود؛ عملیات طولانی روی رشتهٔ اصلی اجرا می‌شوند (لغو = کلیک روی دکمهٔ دیگر).

۷۰ تست خودکار (حدود ۸۵ ثانیه): بارگذاری و اعتبارسنجی تصویر، اصلاح کجی، تشخیص ناحیهٔ نمودار، ریاضیات کالیبراسیون، تشخیص محور با OCR، استخراج منحنی / Marker / نوار خطا / میله / دایره / باند / دو محور / چندپنلی در برابر داده مرجع، PDF برداری، برازش منحنی (از جمله رد عبارت‌های دلخواهِ ناامن)، مشتق / انتگرال / آمار / تقاطع، همهٔ خروجی‌ها (ساختار و فرمول Excel، Word، PDF، CSV، رفت‌وبرگشت JSON، ZIP)، ذخیرهٔ پروژه در SQLite، Undo/Redo، محافظت در برابر ZIP-slip و آزمون دودی (smoke) هر ده صفحهٔ داشبورد.

**وضعیت صادقانهٔ این نسخه**

* موتور استخراج، ماژول‌های تحلیل و خروجی‌ها با مجموعهٔ تست و اسکریپت اعتبارسنجی بالا اجرا و راستی‌آزمایی شدند (پایتون ۳٫۱۲، Tesseract 5).
* **پایتون ۳.۸ تا ۳.۱۱:** سورس به‌صورت ایستا برای سازگاری با ۳.۸ بازبینی شد (بررسی سینتکس با `ast.parse(feature_version=(3, 8))`، نبود API های جدید کتابخانهٔ استاندارد، نبود استفادهٔ زمان‌اجرای `X | None` / `list[int]`، و جایگزینی فراخوانی‌های ویژهٔ NumPy 2 و SciPy جدید با توابع کمکی در `analysis/_compat.py`). اما مجموعهٔ تست فقط روی **پایتون ۳.۱۲ اجرا شد**؛ اگر روی پایتون قدیمی‌تر مشکلی دیدید، لطفاً traceback را گزارش دهید.
* **رابط Streamlit / Plotly در محیط ساخت اجرا نشد** (بدون شبکه برای نصب Streamlit). هر ده ماژول داشبورد با یک جایگزین وفادار (`tests/fake_streamlit.py`) اجرا شد که مسیرهای کد پایتون را می‌آزماید، اما ظاهر واقعی در مرورگر **بررسی نشده است**. اگر در اجرای اول مشکلی در رابط دیدید، همراه با traceback ترمینال / `data/logs` گزارش دهید.
* مسیر PDF فارسی از راه `arabic-reshaper` / `python-bidi` اینجا اجرا نشد؛ PDF فارسی از راه LibreOffice و گزارش Word فارسی اجرا و بصری بررسی شدند.
* به همین دلیل بازهٔ نسخهٔ Streamlit و Plotly در `requirements.txt` به نسخهٔ آزموده‌شده قفل نشده است.

## ۱۵. حریم خصوصی و امنیت

* هیچ‌چیز از رایانهٔ شما خارج نمی‌شود: بدون API ابری، بدون ردیابی (`gatherUsageStats = false`)، سرور روی `127.0.0.1`.
* فایل‌های بارگذاری‌شده اعتبارسنجی می‌شوند (پسوند، magic bytes، حجم) و فقط به‌عنوان تصویر رمزگشایی می‌شوند — هرگز اجرا نمی‌شوند. عبارت مدل دلخواه با فهرست مجاز بررسی و با SymPy تفسیر می‌شود (متن کاربر با `eval` اجرا نمی‌شود). بازیابی ZIP در برابر path traversal محافظت دارد.
* پروژه‌ها، آپلودها، خروجی‌ها، لاگ‌ها و پایگاه SQLite در `data/` هستند (با `GI_DATA_DIR` قابل تغییر).
